# .hammerspoon

Hammerspoon 脚本集合。`init.lua` 加载并启动以下模块，并集中配置当前启用的快捷键，配置加载完成后显示提示。

| 脚本名称 | 功能 | 绑定（监听）快捷键 / 事件 |
| --- | --- | --- |
| [init.lua](init.lua) | 配置入口，统一配置快捷键并启动全部功能模块。 | 加载或重新加载配置时执行。 |
| [window_resize.lua](modules/window_resize.lua) | 打开尺寸选择器，将触发快捷键时的聚焦窗口调整为预置或自定义尺寸，并在当前屏幕的可用区域居中；按屏幕缩放比例将像素转换为 points。 | **绑定**：`Ctrl + Cmd + Shift + 5`。 |
| [lockscreen_camera.lua](modules/lockscreen_camera.lua) | 锁屏显示器唤醒后每秒拍一张，解锁或再次黑屏时结束并合并发信。成功解锁后额外每 30 秒拍一张，共 10 张，再单独发送一封邮件；失败也通知。照片保存到 `~/Downloads/异常解锁/` 下的独立目录。 | **监听系统事件**：锁屏、解锁、显示器休眠和唤醒（`screensDidLock`、`screensDidUnlock`、`screensDidSleep`、`screensDidWake`）；无快捷键。 |
| [close_last_window_hide.lua](modules/close_last_window_hide.lua) | 关闭窗口后，若应用已无窗口则自动隐藏应用；Finder 会排除桌面窗口。 | **监听**：`Cmd + W`，不拦截应用原有的关闭窗口操作；不处理同时按下 `Shift`、`Option` 或 `Ctrl` 的组合。 |
| [blink_reminder.lua](modules/blink_reminder.lua) | 每 20 分钟提醒一次，可延后 1 / 5 / 10 分钟；关闭提醒需经过两次确认，各阶段的随机位置按钮均需连续悬停 10 秒后才能点击。 | **测试快捷键（默认不绑定）**：`Ctrl + Option + Cmd + B`，启用后可立即显示提醒。 |

修改快捷键时，在 `init.lua` 中调整对应模块的 `start()` 参数即可，例如：

```lua
require("modules.window_resize").start({
    mods = { "ctrl", "cmd", "shift" },
    key = "5",
    bind = true,
})
```

`mods` 支持 `ctrl`、`alt`（Option）、`cmd`、`shift`。`bind = false` 跳过快捷键绑定或按键监听；`bind = true` 或省略该字段时启用。模块内部负责注册或监听，修改后重新加载 Hammerspoon 配置生效。

眨眼提醒的测试快捷键配置为 `{ mods = { "ctrl", "alt", "cmd" }, key = "B", bind = false }`，定时功能照常启动；需要测试时将 `bind` 改为 `true` 即可，也可在 Hammerspoon Console 执行 `require("modules.blink_reminder").show()` 立即显示提醒。窗口尺寸和眨眼提醒模块不传参数时也会跳过快捷键绑定。关闭窗口后隐藏应用的模块必须传入配置，监听的快捷键须与目标应用实际的关闭窗口快捷键一致；修改监听配置不会更改应用自身的快捷键。

窗口尺寸支持预置 `1200 × 760`、`1280 × 800`、`640 × 400`（单位：px），也支持输入 `1280x720`、`1280×720`、`1280 720` 或 `1280,720`，按回车应用。没有聚焦窗口或窗口处于全屏状态时不执行。

锁屏拍照模块需要安装 `ffmpeg` 和 `msmtp`（`brew install ffmpeg msmtp`），配置 msmtp 的 SMTP 账户，并在脚本中设置发件邮箱、收件邮箱、设备名称及邮件主题。使用 FFmpeg 持续打开系统默认摄像头，通过 [image2 图片序列输出](https://ffmpeg.org/ffmpeg-formats.html#image2-2)每秒保存一张 JPEG，默认分辨率为 640 × 480；不保存录像或采集音频。需要 macOS 摄像头权限，模块本身不显示弹窗，日志写入 Hammerspoon Console。

显示器唤醒后立即启动摄像头，启动完成后按每秒一张的频率拍照，没有固定拍摄总时长。解锁成功时停止拍照；如果先再次黑屏，则暂停并结束这一轮，下次锁屏唤醒时重新开始。每轮照片保存在独立子目录中，文件名为 `000001.jpg`、`000002.jpg` 等。写入完整后才纳入邮件附件。

本轮成功解锁后，先发送锁屏期间的照片邮件，再开始独立的解锁后拍照：首张在解锁 30 秒后开始拍摄，之后每 30 秒拍一张，共 10 张，正常约 5 分钟后合并发送另一封邮件。新邮件主题增加「解锁后拍照」，照片保存在 `after_unlock_时间_标识/` 子目录中。每张单独启动 FFmpeg，预热 0.5 秒后拍一张即退出，两次拍照之间释放摄像头。

解锁后拍照期间，若再次锁屏、黑屏或停止模块，会结束该轮并发送已有照片；首张尚未开始就被取消时不额外发送空邮件。单张拍照失败或 15 秒超时，会结束该轮并发送已有照片及原因。只有本模块监测到的锁屏唤醒会触发这轮后续拍照，普通解锁不会单独启动；重复解锁事件也不会重置计时。

拍照前先将摄像头时间戳归零，再按 `PHOTO_INTERVAL` 选择真实帧，并禁用自动补帧，避免非零起始时间戳导致瞬间生成大量重复照片。

拍照期间不定时发邮件，等解锁成功、再次黑屏、模块停止或拍照任务失败时，将这一轮照片合并到一封邮件中统一发送。未解锁且显示器仍亮着时持续拍照，邮件等待本轮结束后发送。快速解锁导致尚未拍到照片、缺少 FFmpeg、摄像头任务失败或连续 15 秒未输出照片时，也会发送邮件，附上已有照片并说明原因；没有可用照片则发送无附件邮件。邮件附件总原始大小上限为 10 MB，超过上限的照片保留在本机，邮件正文会说明。

邮件忙时按顺序排队，发送时才读取照片附件，避免把所有待发送照片内容保留在内存；发送失败记录日志，目前没有自动重试。重复唤醒事件不会重复启动摄像头，新的黑屏后唤醒无需等待原来的 5 秒冷却期。可在脚本顶部修改 `PHOTO_INTERVAL`、`AFTER_UNLOCK_INTERVAL`、`AFTER_UNLOCK_COUNT`、`CAMERA_DEVICE` 和 `CAMERA_SIZE`。模块还提供 `stop()` 用于停止监听及拍照。

关闭窗口后隐藏应用的模块会在 `Cmd + W` 按下约 0.15 秒后检查原前台应用是否仍有窗口。
